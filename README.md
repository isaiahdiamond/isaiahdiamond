What I'm building

intern-app

An internship application assistant that runs locally. It pulls new listings for the roles you pick during onboarding, reads each job description into a skills database, and tracks what you've applied to. You can save resume versions and see which skills employers keep asking for that you don't show yet.

It finds and tracks jobs only. It doesn't rewrite resumes or submit anything. I use it for my own summer 2027 search.
